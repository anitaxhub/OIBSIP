# BloomBox - Personalised Skincare Subscription Landing Page

**Oasis Infobyte Internship (OIBSIP) | Web Development | Level 1, Task 1**
**Intern:** Anita Bashir

A responsive, static landing page for **BloomBox**, a fictional skincare subscription that builds a monthly routine around each customer's skin. Built with plain HTML5 and CSS3 (no JavaScript).

## Objective
Build a visually polished static landing page for a product, service or brand, to practise foundational HTML/CSS layout skills.

## Features (Task Checklist)
- [x] Sticky navigation bar with 4 links and a call-to-action button
- [x] Hero section with headline, subheadline, CTA button and an arch-shaped hero photo
- [x] Four content sections: How it works, Inside the box, Plans and Reviews (with star ratings and customer portraits)
- [x] Footer with placeholder contact and social links
- [x] Consistent colour palette across all sections
- [x] Responsive layout using Flexbox and CSS Grid, tested down to 390 px width
- [x] No element overlap: padding, margin and `box-sizing` set deliberately
- [x] Clean typography with a clear heading vs body size scale

## Tech Stack
- HTML5 (semantic tags: `header`, `nav`, `main`, `section`, `article`, `ol`, `blockquote`, `footer`, `address`)
- CSS3 (custom properties, Flexbox, Grid, CSS counters, media queries)
- Google Fonts: Instrument Serif (headings) and Hanken Grotesk (body)
